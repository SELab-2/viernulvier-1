# VierNulVier Archive Documentation

This folder contains documentation describing the structure and design of the VierNulVier Archive website.

## Documents

### Domain Model

**File:** `Domeinmodel.md`

This document describes the **conceptual domain model** of the archive system.  
It explains the main entities used in the system and how they relate to each other.

Main concepts include:

- Production
- Event
- Location
- EventPrice
- Tag
- Image and Crop
- CustomProductionField
- User and Admin
- Blog and BlogPost

The document also contains a **Mermaid class diagram** that visualizes the relationships between these entities.

---

### Website Mockup Documentation

**File:** `Mock.md`

This document explains the **structure and functionality of the website based on the design mockups**.

It describes:

- the homepage
- the archive browsing interface
- production detail pages
- series (festival) pages
- the admin interface
- how productions and events can be created and managed

It also includes links to the **Figma mockups** used to design the interface.

---

## Purpose of this Documentation

Together these documents describe:

- **what the system contains** (domain model)
- **how users interact with it** (website structure and mockups)

This documentation is intended for developers, designers, and project stakeholders working on the VierNulVier Archive.
